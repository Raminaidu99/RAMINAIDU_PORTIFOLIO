# Sankarapu Raminaidu - Portfolio

Welcome to the source code for my personal portfolio! This is a fully responsive, modern web portfolio built using HTML, CSS, and vanilla JavaScript. 

## 🚀 Features
- **Responsive Layout**: Designed to look great on desktop, tablet, and mobile displays.
- **Glassmorphism & Gradients**: Uses modern web design aesthetics to create a premium feel.
- **Interactive UI**: Micro-animations and hover effects that enhance the user experience.
- **SEO Optimized**: Standard best practices implemented for better search engine visibility.

## 🛠️ Technology Stack
- **HTML5**: Semantic structure.
- **CSS3 (Vanilla)**: All custom styling, using CSS variables for a cohesive design system.
- **JavaScript (Vanilla)**: Used for responsive navigation, scroll reveals, and interactivity.

## 🏃‍♂️ Getting Started
To view this project locally, simply clone the repository and open `index.html` in your browser, or serve it using any local development server:

```bash
# Clone the repository
git clone https://github.com/Raminaidu99/RAMINAIDU_PORTIFOLIO.git

# Navigate to the project directory
cd RAMINAIDU_PORTIFOLIO

# Serve using npx (requires Node.js)
npx serve .
```
